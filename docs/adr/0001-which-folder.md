# ADR-000: Choosing the location of my semester-long project

**Status:** Proposed | Accepted | Superseded by ADR-00X
**Date:** 2026-08-27

## Context

I will be working on a semester-long project using various types of files. These files need to be kept in an organized and easy to find manner.

## Decision

I am creating a directory titled "rhet350" where my "llms-project" folder will reside.

## Alternatives considered

One option was to include everything in my preexisting Downloads folder. A benefit of choosing this route would have been the fact that the name of the folder is easy to remember, and I would not have had to remember a new directory name when searching for my work. However, I chose to create a new folder insterad because my Downloads folder has many files in it already. Things would be less organized and get lost very easily. Creating a new folder is an overall cleaner approach.


Another option was to choose my Desktop directory. The pros and cons of Desktop are identical to the ones for Downloads above.

## Consequences

What this makes easier, and what it makes harder. The second half is the one
that gets skipped and the one that is worth reading.

I would consider revisiting this decision if I find it difficult to remember the names of my directories in the future (an issue which happens to me on a consistent basis).
